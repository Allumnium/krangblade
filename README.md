# Krangblade

A minimal **Godot 4** starter for a 2D indie game. The initial scene shows a title screen and is ready to replace with your game's first prototype.

## Run it

1. Install [Godot 4](https://godotengine.org/download/).
2. Clone the repo:
   ```sh
   git clone https://github.com/Allumnium/krangblade.git
   ```
3. In Godot's Project Manager, click **Import** and select the cloned `project.godot`.
4. Press **F5** to run the project.

## Structure

- `project.godot` — project configuration
- `scenes/main.tscn` — starting scene
- `scripts/main.gd` — starting GDScript
- `.gitignore` — generated files excluded from version control

Designed for Godot 4.x using the Compatibility renderer. There are no required plugins or external assets.
